# Course 3: Connect and Protect - Networks and Network Security

## Overview
Network architecture, protocols, network security hardening, and attack analysis.

## Portfolio Activities

### Activity 1: Analyze Network Attacks
- **Description**: Investigate network attack scenarios and develop mitigation strategies
- **Skills**: Attack pattern recognition, threat analysis, security recommendations
- **File**: [`analyze-network-attacks.md`](./analyze-network-attacks.md)
- **What's Included**:
  - DDoS attack analysis (ICMP flood)
  - Description of attack symptoms and characteristics
  - Impact assessment on organization's network
  - Potential consequences (immediate and long-term)
  - Security measures to prevent future attacks
  - Technical and administrative controls

### Activity 2: Apply OS Hardening Techniques
- **Description**: Implement system hardening to improve security posture
- **Skills**: Linux/Windows hardening, security configuration, patch management
- **File**: [`os-hardening-techniques.md`](./os-hardening-techniques.md)
- **What's Included**:
  - Linux server hardening (Ubuntu)
    - Disable unnecessary services
    - Strong password policies
    - Firewall configuration (UFW)
    - Fail2Ban intrusion prevention
    - Automated security updates
  - Windows workstation hardening
    - Windows Defender configuration
    - BitLocker encryption
    - Application whitelisting (AppLocker)
    - UAC and Windows Update policies

### Activity 3: Analyze Network Layer Communication
- **Description**: Capture and analyze network traffic using tcpdump and Wireshark
- **Skills**: Packet analysis, protocol analysis, traffic pattern recognition
- **File**: [`network-layer-communication-analysis.md`](./network-layer-communication-analysis.md)
- **What's Included**:
  - TCP/IP model and OSI layers explanation
  - tcpdump packet capture techniques
  - DNS traffic analysis and tunneling detection
  - TCP three-way handshake analysis
  - ICMP traffic analysis
  - HTTP vs. HTTPS security comparison
  - Network attack detection (port scans, ARP spoofing, C2 traffic)

### Activity 4: NIST CSF Incident Report (Bonus)
- **Description**: Apply NIST Cybersecurity Framework to DDoS incident response
- **Skills**: NIST CSF framework, incident response, comprehensive security analysis
- **File**: [`incident-report-nist-csf.md`](./incident-report-nist-csf.md)
- **What's Included**:
  - Full NIST CSF 5-function analysis (Identify, Protect, Detect, Respond, Recover)
  - Detailed incident timeline and root cause analysis
  - IOC documentation
  - Comprehensive remediation recommendations

## Key Learnings
- Network protocols (TCP/IP, DNS, HTTP/HTTPS)
- Network security architecture
- Firewalls and VPNs
- Intrusion detection systems
- Packet analysis with Wireshark

## Tools Used
- Wireshark
- tcpdump
- Network diagrams
